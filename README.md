# RANK TACTICS v0.4 — DUEL LAB

現在のトップページは直接操作の1対1アクションです。操作は末尾のv0.4節を参照してください。従来の戦術版は `?mode=strategy` に残しています。

スマホ横画面対応の3対3・市街地戦術シミュレーション。TypeScript / PixiJS 8 / React 19 / Vite / Vitest。

## 起動と検証

Node.js 22.12以降（検証環境: 24.19）で実行します。外部サービス・APIキーは不要です。

```sh
npm ci
npm run dev
npm test
npm run build
```

## 遊び方

1. 必要ならSEEDを入力して「新規試合」。同じシードと同じタイミングの指示で結果が再現します。
2. 「開始 / 再開」で戦闘開始。1倍・2倍・4倍、一時停止を切り替えられます。
3. マップか部隊一覧で味方を選択し、空きマスで移動先、視認中の敵で攻撃対象を指定します。一時停止中も指示できます。
4. 「挟撃」は外周経由の側面移動、「援護」はアタッカーへの追従、「待ち伏せ」はその場で防御と射撃。「自律」で通常の索敵に戻ります。戦術変更は個別の移動・攻撃指示を解除します。
5. 全滅または120秒で終了。撃破100点＋生存50点/名で比較、同点は引き分け。「同じシードで再戦」でやり直せます。

A=アタッカー、G=ガンナー、S=スナイパー。青緑が味方、朱色が視認中の敵。HPバーと記号を併記します。COVERは遮蔽物による防御状態（被ダメージ35%軽減）。「?」は8秒間保持される最終確認地点で、現在位置ではありません。

## 構成・ルール

- `src/engine.ts`: React/Pixi非依存の純粋なシミュレーション。0.1秒刻み、seed付きxorshift乱数、グリッド経路探索、射線、射撃、防御、得点。
- `decide(unit, intel)`: AIの入力境界。生存味方・視認して共有された敵の記録・静的地図だけを入力し、全敵状態にはアクセスしません。接敵を失った記録は追跡移動に使えますが射撃判断には使いません。
- `src/Battlefield.tsx`: Pixi描画とポインター入力。敵の描画も味方の現在の視認に限定。
- `src/main.tsx`: 試合操作、固定刻みの時間管理、React UI。
- `src/engine.test.ts`: 再現性、終局、射線、経路、情報制限、移動、得点、状態の不変条件。

v0.1のマップは固定です。挟撃は外周ウェイポイントによる簡易実装で、敵に応じた複数人の同期包囲は行いません。リプレイ保存、オンライン対戦、音声、複数マップは未実装です。防御は射撃時・待ち伏せ時の自動動作です。


## v0.2: 介入できる市街地戦

- 中央の通信局（半径3マス）を単独チームで確保すると毎秒3点。両軍がいる間は加点停止。残り30秒は毎秒6点。決着は撃破・生存・確保点の合計です。
- 射撃には予兆があり、とくに狙撃は1.6秒のLOCK表示が出ます。着弾位置から1マスを超えて移動すると回避できます。敵AIも視認した狙撃の予兆だけを使って回避します。
- 選択した味方の「ダッシュ」で2.5秒間移動速度2倍（再使用12秒）。マップで移動先を指示してください。
- 「煙幕」は1人1回。現在地の半径2マスを6秒間遮蔽し、敵味方両方の視界と射撃を遮断します。最終確認地点の記憶は残ります。
- 建物の隣のCOVER表示で被ダメージ35%減。射撃中と待ち伏せ中の防御は別途20%減。
- 銃声・着弾音は「音 OFF」を押すと有効。初期状態は無音です。音がなくてもLOCK・着弾・被弾・危険警告で判断できます。
- 選択中の味方が撃破されたら、生存している味方に選択が移ります。

描画演出は乱数生成器を使わず、戦闘シードに影響しません。敵の照準・射撃元・ユニット表示は現在の味方視界に制限されます。

## v0.3: 装備・情報戦・作戦会議・シーズン

最初に作戦会議が開きます。3名それぞれにメイン4枠とサブ4枠を編集し、各バンクで1つを起動。試合中は8枠のボタンで切替可能です。両手盾では射撃できず、防御が強化されます。範囲弾は着弾周辺2マスに半分のダメージ（味方にも命中）。攻撃武器を2つ起動すると火力と長い方の射程を使用します。

隠密はレーダー反応をなくし、目視距離も2マスに制限。射撃すると4秒間露見します。レーダーは24マス以内の反応を約4マス単位で共有し、HPも射撃用の正確な位置も得られません。射撃できるのは目視した相手だけです。夜の目視は6マス。水没区の中央帯では移動が遅く、狙撃の射程と威力が落ちます。

各隊がマップを1つ提出し、シードで片方を選びます。開幕は中央集中・三方向・待ち受けを選択。優先目標は視認した時だけ追跡します。遠見隊・烈火隊・静波隊は装備と初動が異なります。

解説席は自隊の共有情報・耐久・配置・公開された確保状態から生成するテキストです。未確認の敵の位置を読み取らず、隠密・撃破・範囲外を断定しません。発言は5秒ごとに更新し直近の履歴を残します。音声実況は未実装です。

シーズンは3戦。結果画面で「結果を記録して作戦会議へ」を押すと勝利3点・引分1点が順位表に入り、装備とシーズンがlocalStorageへ保存されます。他隊同士の試合は固定結果です。試合途中の再開、複数隊同時対戦、自由文の作戦指示、クラウド保存は未実装です。

## v0.4: DUEL LAB — 直接操作の1対1

トップページは、操作感を検証する60秒の1対1アクションになりました。旧戦術版は画面内リンクまたは `?mode=strategy` で開けます。

- **移動**：スマホは左スティック。PCはWASD／矢印。照準は相手への自動照準です。射撃には移動方向からの偏差補助があります。
- **斬撃**：右の斬撃ボタン／Kを1回押すごとに踏み込んで攻撃。近距離22ダメージ、再使用0.65秒。外すと隙ができます。
- **射撃**：右の射撃ボタン／Jを長押し。1発6ダメージ。弾に飛翔時間があり、壁で止まります。
- **盾**：右の盾ボタン／L・Spaceを長押し。移動が遅くなりエネルギーを消費。離すと回復します。
- **ジャストガード**：盾を出した直後0.19秒に前方から攻撃を受けると弾き返します。敵が怯み、1.8秒以内の斬撃が38ダメージに強化されます。射撃は反射します。
- 敵は攻撃前に赤い線／斬撃範囲を表示し、予兆開始時の位置へ攻撃します。プレイヤーの入力は読みません。
- HPが0になるか60秒で終了。残りHPを比較。同点は引き分け。結果画面から再戦できます。
- 一時停止、タブ非表示時の停止、マルチタッチのキャンセル処理に対応。音は初期OFFです。

`src/duel.ts` が120Hz固定刻みの戦闘ロジック、`src/Duel.tsx` が入力・Pixi描画・HUD。乱数なしで同じ入力を再現できます。武器3種の手触りを試す小規模な試作で、味方への指示や8枠切替はこのモードにはまだありません。
